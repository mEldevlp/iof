# iof-web

Веб-панель для `iof`, только просмотр. Страницы:

- **Обзор** (`/`) — состояние узлов как в `iof status`, ретрансляторы, группы Hysteria2, клиенты AWG.
- **Hysteria2** (`/hy2.html`) — группы ссылок: копирование всех ссылок для Hiddify,
  QR всей группы и каждой ссылки, проверка, что группа не отстала от узлов
  (тогда нужен `iof hy2 refresh`), состояние Hysteria2 на узлах.

Ставится вместе с `iof` через `install.sh` в корне репозитория (см. README там) в
`/opt/iof-web`, запускается systemd-сервисом `iof-web` от root. Нужен только `python3`,
для QR-кодов ещё `qrencode`.

## Доступ и безопасность

Панель слушает только `127.0.0.1:8088`, заходить через SSH-туннель:

```
ssh -L 8088:127.0.0.1:8088 пользователь@сервер
```

У панели root-доступ ко всем серверам через `iof`, а страница Hysteria2 показывает
ссылки с паролем, поэтому открывать порт наружу не нужно. Если всё же нужно
(например, за nginx с HTTPS), задай пароль в `/root/iof/web.env` (права 600),
иначе на не-loopback адресе сервер не запустится:

```
IOF_WEB_PASSWORD=длинный-случайный-пароль
IOF_WEB_LISTEN=127.0.0.1:8088
```

Ключи и конфиги AWG панель не отдаёт, только имена клиентов и узлов.

## API

- `GET /api/dashboard` — данные обзора. Опрос узлов идёт через `iof api status`
  (SSH на все узлы), результат держится 20 секунд (`IOF_WEB_TTL`), одновременные
  запросы ждут один общий опрос. `?force=1` обновляет, но не чаще раза в 5 секунд.
- `GET /api/hy2` — группы Hysteria2 со ссылками и состояние узлов.
- `GET /api/hy2/qr?g=<логин>&i=<номер|all>` — QR в SVG через `qrencode`.

`index.html?demo` и `hy2.html?demo` работают на встроенных примерах, без сервера.
