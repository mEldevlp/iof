Перенести управление на другой сервер

Новый сервер станет управляющим, а этот останется VPN-узлом. Клиенты подключаются к узлам напрямую, поэтому их ссылки и ключи не меняются.

Новый управляющий сервер

IPv4 или домен. Ubuntu или Debian, лучше чистый сервер

Не root — нужен sudo без пароля (NOPASSWD)

Ключ без пароля. Ключ PuTTY (.ppk) сначала экспортируй: PuTTYgen → Conversions → Export OpenSSH key

Как идёт перенос

          
    
            
  1. iof заходит на новый сервер и кладёт туда свой ключ
    2. 
            
  2. ставит там iof и панель той же версии, что здесь
    3. 
            
  3. блокирует изменения здесь и копирует туда /root/iof, ключ iof, шаблон Hysteria2 и доверенные ключи узлов
    4. 
            
  4. в nodes.conf нового сервера этот становится обычным узлом
    5. 
            
  5. проверяет, что новый сервер видит все узлы
    6. 
            
  6. «Завершить перенос» в панели нового сервера снимает управление отсюда и переносит задания cron
    7. 
          

          
До завершения перенос можно отменить. Старые данные iof после завершения
            остаются на этом сервере в /root/iof.moved-…, их можно удалить, когда всё проверишь.
