Настройки

  • Действия из бота

    Главные админы смогут запускать из бота проверку узлов, перезапуск Hysteria2 и группы ссылок, каждое действие — с подтверждением. Удаление узлов, перенос и обновление — только в панели.

  • Ссылки Hysteria2

    Бот выдаёт админам ссылки групп с QR-кодами. В ссылках пароль: выключи, если не хочешь держать их в Telegram.

  • Тихие часы

    Уведомления в это время приходят без звука, кроме админов со звуком в тихие часы.

Админы

Неиспользованные приглашения

    Уведомления

    Когда приходят

    Команды на сервере

    sudo iof bot show
    включён ли бот, админы и неиспользованные приглашения
    sudo iof bot token
    задать токен: спросит, не показывая; пустой ввод удаляет токен и выключает бота
    sudo iof bot on, off
    включить или выключить бота
    sudo iof bot invite main
    код приглашения главного админа (regular — обычного)
    sudo iof bot admin set ID notify nodes,audit
    какие уведомления получает админ: типы через запятую, all или off
    sudo iof notify nodes проверка
    пробное уведомление: придёт тем, у кого отмечен этот тип
    sudo iof bot admin del ID
    удалить админа: бот перестанет ему отвечать
    iof-web · бот работает внутри панели: остановится панель — остановится и бот. Токен и коды приглашений на сервере не показываются
