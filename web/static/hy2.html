Команды на сервере

          

            
sudo iof hy2 add "Подпись"
создать группу ссылок по всем узлам (повтор с той же подписью пересобирает её)

            
sudo iof hy2 del "Подпись"
удалить группу (в режиме userpass удаляет и пользователя)

            
sudo iof hy2 refresh
пересобрать все группы после смены узлов, IP, пароля или ретранслятора

            
sudo iof hy2 install all
поставить Hysteria2 на новые узлы, затем они попадут в группы

            
sudo iof hy2 restart all
перезапустить Hysteria2 на узлах; на одном узле — кнопкой на его странице
